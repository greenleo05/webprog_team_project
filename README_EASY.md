# 🎮 컴공생 마법소녀의 하루: 초등학생도 1분 만에 이해하는 게임 설명서!

안녕하세요, 미래의 멋진 마법소녀와 개발자 친구들! 
지금부터 우리가 만들고 즐길 재미있는 벽돌깨기 게임 **"컴공생 마법소녀의 하루"**가 어떤 게임인지 아주 쉽고 재미있게 알려줄게요! 😊

---

## 🌟 1. 이 게임은 어떤 이야기인가요?
컴퓨터공학과에 다니는 주인공은 낮에는 평범한 대학생이지만, 컴퓨터에 에러(버그)가 생기거나 곤란한 일이 생기면 마법 지팡이를 든 **마법소녀**로 변신해요!
마법소녀가 아침에 집에서 나와서 밤늦게 학교 과제를 끝마칠 때까지 겪는 파란만장한 하루를 담은 게임이랍니다. 
우리는 마법 공을 튕겨서 하루 동안 생기는 온갖 방해물들을 모두 깨부수고, 무사히 과제를 제출해 **A+ 학점**을 받아야 해요!

---

## ⏰ 2. 마법소녀의 하루 일과 (스테이지 소개)
마법소녀는 아침 8시부터 밤 11시까지 총 5개의 스테이지(교시)를 지나가게 돼요. 각 시간마다 독특한 미션이 기다리고 있답니다!

| 시간 | 스테이지 이름 | 무슨 일이 일어나나요? (쉬운 설명) |
| :--- | :--- | :--- |
| **08:00** | 🚇 **1교시: 지하철 (등굣길)** | 아침 지하철은 사람이 너무 많아서 지각할 것 같아요! 공을 던져 지하철 승객들 사이로 길을 뚫고 지나가요. |
| **10:00** | 😴 **2교시: 교수님의 지루한 수업** | 눈꺼풀이 무겁고 졸음이 쏟아져요! 몰려오는 졸음 귀신들을 공으로 쳐서 날려버리고 열심히 수업을 들어요. |
| **12:00** | 🍔 **3교시: 맛있는 점심시간 (학식)** | 신나는 밥 시간! 밥 먹을 때는 아무도 마법소녀를 방해할 수 없어요. **공이 바닥에 떨어져도 죽지 않는 무적 상태**가 되니, 맛있는 음식 블록들을 마음껏 부수며 점수를 왕창 모아보세요! |
| **17:00** | 😤 **4교시: 조별과제 대소동** | 아무 일도 안 하면서 숟가락만 얹으려는 '얌체(트롤) 조원'들이 나타났어요! 요리조리 도망 다니는 얌체 조원들을 공으로 콩! 맞춰서 버릇을 고쳐주세요. |
| **23:00** | 💻 **5교시: 과제 끝! 버그 물리치기** | 밤 11시, 과제 제출 마감 1시간 전! 컴퓨터가 삐용삐용 에러 코드(Uncaught TypeError)를 뿜어내고 있어요! 빨간 에러 코드들을 다 없애면, 최종 보스인 **거대 세미콜론( ; )**이 나타나요. 이 보스를 이겨야 집에 갈 수 있어요! |

## 🕹️ 3. 어떻게 조종하나요?
- **마우스 움직이기**: 마우스를 왼쪽, 오른쪽으로 움직이면 화면 아래에 있는 마법소녀가 마우스를 따라서 슥슥 움직여요.
- **공 튕기기**: 날아오는 공을 마법소녀의 몸(막대기)으로 튕겨서 위로 다시 올려보내세요!
  - **마법 튕기기 비법!**: 공이 마법소녀의 **왼쪽 끝**에 맞으면 왼쪽 대각선으로 멀리 날아가고, **오른쪽 끝**에 맞으면 오른쪽 대각선으로 멀리 날아가요! 원하는 곳으로 공을 보내고 싶다면 닿는 위치를 잘 조절해 보세요!

## 📢 4. 이것만 기억하면 나도 게임 왕! (핵심 규칙)
1. **하트(목숨)는 소중해요**: 공을 아래로 떨어뜨리면 하트(♥)가 1개씩 사라져요. 하트가 모두 없어지면 게임오버예요! (단, 맛있는 점심시간에는 떨어뜨려도 괜찮아요!)
2. **시간제한 60초**: 각 스테이지마다 시계가 똑딱똑딱 60초부터 거꾸로 흘러가요. 시간이 다 가기 전에 벽돌을 모두 깨야 해요!
3. **일시정지**: 게임 중에 너무 화장실에 가고 싶거나 쉬고 싶다면, 키보드에서 **`P` 키**나 **`ESC` 키**를 누르거나, 화면 위의 일시정지(⏸️) 버튼을 누르면 게임이 잠깐 멈춰요!

## 🎓 5. 내 최종 성적(학점)은?
스테이지를 빨리 깨면 남은 시간만큼 보너스 점수를 엄청 많이 받아요! 게임이 모두 끝나면 내가 얻은 점수에 따라 성적표를 받게 됩니다.

- 🥇 **600점 이상**: **A+** (최고의 마법소녀 천재 개발자!)
- 🥈 **500점 이상**: **A** (아주 훌륭해요!)
- 🥉 **350점 이상**: **B** (잘했어요!)
- 🏅 **200점 이상**: **C** (조금만 더 노력해 봐요!)
- 🎖️ **100점 이상**: **D** (과제가 조금 힘들었나 봐요!)
- 😢 **100점 미만**: **F** (재수강의 슬픔이... 다시 도전해 봐요!)

마법소녀를 도와 버그를 모두 물리치고 **A+** 학점을 노려보세요! 화이팅! 🚀
